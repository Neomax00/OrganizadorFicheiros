"Organizador de Ficheiros"

Objetivo:
Criar uma aplicação em Python , que analisa uma pasta, indica e contabiliza os ficheiros existentes e identifica as extensões dos ficheiros (em expecifico .py, .txt e .csv) 

Ferramentas Utilizadas:
- Python e Spyder
- Git, Gitbash e GitHub
- Vim

Instruções de Execução:
1. Abrir o ficheiro "organizador.py" no Spyder , verificando que este está na pasta de trabalho.
2. Executar o script e visualizar os resultados na consola.
